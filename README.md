# 🎮 Rock Paper Scissors Game (Python)

A simple command-line implementation of the classic **Rock, Paper, Scissors** game using Python. The game allows a player to compete against the computer, where the computer's choice is generated randomly.

## 🚀 Features

* User vs Computer gameplay
* Random computer choice using Python's `random` module
* Determines the winner based on the game rules
* Beginner-friendly code structure using functions
* Simple and interactive command-line interface

## 🛠️ Technologies Used

* Python 3
* `random` module

## 📖 Game Rules

* 🪨 Rock beats Scissors
* ✂️ Scissors beats Paper
* 📄 Paper beats Rock
* If both players choose the same option, the game ends in a tie.
